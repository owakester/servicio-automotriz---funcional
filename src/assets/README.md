# Identidad del taller

`brand.json` contiene el nombre Brabus Service y el archivo original `logo.jpeg`
incorporado como una imagen JPEG en base64, sin modificar sus píxeles.

El portal, el icono de la pestaña y las órdenes para imprimir comparten esta
imagen. Al estar incorporada en el comprobante, no depende de internet ni de
que el servidor local esté encendido cuando se abre una orden guardada.

El ajuste visual del espacio negro alrededor del logo se realiza con CSS;
la imagen original se conserva completa.
